# Frontend

Vue 3 + TypeScript + Vite + Pinia + Vue Router + Tailwind. Код размещён в FSD-каталогах: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

Сейчас реализованы layout, navigation, CRUD Streamers, пакетное добавление Twitch-ников по одному на строку, изменение неотрицательного приоритета числовым полем, поиск Twitch Clips по выбранному стримеру и диапазону дат (по умолчанию последние 7 календарных дней) и добавление их в избранное без автоматического скачивания. Добавление стримеров открывается в модальном окне; логика и UI списка находятся в `features/streamer-manager`, а `StreamersPage` остаётся тонкой route-страницей. Страница `Pipeline` — доска из трёх колонок: «Избранное», «Скачанные» и «Готовые видео». При «В работу» или переносе в третью колонку сначала открывается выбор шаблона, а затем редактор конкретного рендера с предпросмотром скачанного видео. Изменения не сохраняются в базовый шаблон. Job создаётся только по кнопке «Отправить на рендер». Скачанный исходник остаётся во второй колонке после завершения, поэтому его можно удалить вручную или повторно отрендерить другим шаблоном. Ручное удаление исходника скрывает карточку из «Скачанных», но не удаляет связанные готовые рендеры. Каждый успешный рендер показывается отдельной карточкой, даже если один исходник отрендерен несколько раз; на карточке видны шаблон и время создания. Удаление такой карточки удаляет только выбранный render, а не исходный clip и не другие его рендеры. «Открыть» показывает видео в модальном окне, а «Скачать» использует same-origin API с attachment-заголовком и запускает сохранение файла. Отдельной страницы видео нет.

В меню шестерёнки есть страницы «Ассеты» и «Шаблоны видео». Ассеты поддерживают S3 upload, preview, create/rename/move/delete folders и rename/move/delete files. Их операции, состояние диалогов и HTTP-вызовы находятся в `features/asset-manager/model/useAssetManager.ts`; UI загрузки, карточек, модалок и workspace с деревом папок — в `features/asset-manager/ui`. `AssetsPage` — тонкая route-страница, которая только подключает `AssetLibraryWorkspace`. Шаблоны имеют default marker, список, duplicate/delete и editor: очерченная рабочая зона 9:16 на `vue-konva`, реальные image/GIF/video previews, drag/resize, hide, duplicate, undo/redo и свойства слоя. Выбор ассета открывает проводник с папками, совместимый с библиотекой ассетов. Финальным источником истины остаётся FFmpeg worker. FSD используется фактически: editor лежит в `features/template-editor`, DTO-типы — в `entities/{asset,template}`, страницы — в `pages`, общие компоненты/API — в `shared`. Biome форматирует и проверяет frontend: `npm run format`, `npm run lint`; production проверка: `npm run build`.

Карточки «Готовых видео» показывают thumbnail исходного Twitch-клипа. Сам render загружается только при открытии модального просмотра.
