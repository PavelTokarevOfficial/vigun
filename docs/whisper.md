# Whisper subtitles

Worker продолжает запускать локальный `whisper-cli`. `WHISPER_MODEL_PATH` сохраняет совместимость с существующей `ggml-tiny.bin`, а его директория (или `WHISPER_MODELS_DIR`) является общим каталогом моделей. В Docker bind-mount `./models:/models` доступен API для управляемой загрузки и worker только для чтения. Файлы не хранятся в Git и переживают пересоздание контейнеров.

Settings получает каталог разрешённых моделей из backend. API скачивает только известные файлы из официального `ggerganov/whisper.cpp` на Hugging Face: сначала в `*.part`, затем после полной загрузки атомарно переименовывает файл. Незавершённый файл не считается установленной моделью. Активную модель удалить нельзя.

Активная модель, preset и advanced-параметры хранятся в singleton-строке `whisper_settings`. При постановке рендера API сохраняет ID, имя и тип активной модели в immutable template snapshot. Worker запускает `whisper-cli` именно с моделью из этого snapshot, поэтому переключение настройки не меняет уже поставленные задания, а карточка готового видео показывает реально зафиксированную для рендера модель. SRT хранится под отдельным ключом для каждой модели; legacy Tiny продолжает использовать прежний ключ. Preset и advanced-параметры worker читает перед транскрибацией. Presets: `fast` (`-bs 1 -bo 1 -nf`), `balanced` (`-ml 10 -sow`, прежнее поведение), `maximum` (`-bs 8`) и `subtitles` (`-ml 42 -sow`). Advanced может переопределить beam size, temperature, максимальную длину сегмента, split-on-word и initial prompt.

Subtitle layer может хранить `whisperModelId`. Редактор предлагает только уже скачанные модели. При постановке рендера модель слоя имеет приоритет над глобальной активной моделью и фиксируется в snapshot; если модель удалена или несколько видимых subtitle-слоёв требуют разные модели, API отклоняет запуск.

Каталог содержит Full и официально опубликованные Q5-варианты Tiny, Base, Small, Medium, Large v3 Turbo и Large v3. Готовых Q4-файлов в официальном каталоге `whisper.cpp` нет, поэтому приложение их не предлагает.

Результат по-прежнему нужен только в SRT (`subtitles/{clipID}/subtitles.srt`). SRT содержит текст и временные интервалы, поэтому FFmpeg может показывать на видео лишь актуальную строку и permanently burn-in её в итоговый MP4.

`WHISPER_MODEL_PATH` обязателен только для worker. API может быть запущен без модели: это позволяет работать со streamer, списком клипов, import и статусами, пока модель ещё скачивается.
